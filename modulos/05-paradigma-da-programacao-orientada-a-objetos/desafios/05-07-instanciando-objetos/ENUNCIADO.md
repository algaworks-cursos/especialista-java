# 05.07 — Desafio: Instanciando objetos e acessando os atributos

Sua tarefa é criar uma classe que representa um `Cachorro`. 

Um cachorro deve ter as seguintes propriedades (atributos):
- Nome
- Raça
- Sexo
- Idade

Crie a classe de execução (`Principal`) com o método `main`. Nele, instancie dois objetos do tipo `Cachorro`, atribua valores para cada uma de suas propriedades e, por fim, imprima essas informações na tela (console).
