# **Especialista Java — AlgaWorks**

Repositório de estudos do curso **Especialista Java** da [AlgaWorks](https://www.algaworks.com/).  
Aqui documento minha jornada aprendendo Java do zero até conceitos avançados, com anotações, exemplos de aula e soluções dos desafios práticos.

---

## **📖 Sobre o Curso**

O **Especialista Java** é um curso imersivo que abrange desde os fundamentos da linguagem até tópicos como Orientação a Objetos, Expressões Lambda, Streams API, operações com datas e muito mais.

---
